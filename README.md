### 8086 Assembly Language Project

## 📌 Project Overview

The **Number System Conversion System** is an 8086 Assembly Language project that performs conversions between different number systems.

The system provides four major conversion operations:

- Decimal → Binary
- Decimal → Hexadecimal
- Binary → Decimal
- Hexadecimal → Decimal

The project demonstrates important Assembly Language concepts such as procedures, loops, stack operations, division, remainder calculation, ASCII conversion, lookup tables, and DOS interrupt services.

---

## 🎯 Objectives

The main objectives of this project are:

- To understand 8086 Assembly Language programming.
- To implement number system conversion algorithms.
- To practice procedures and loops.
- To understand stack operations.
- To use division and remainder operations.
- To handle ASCII character conversion.
- To use DOS interrupt services.
- To develop a menu-driven Assembly Language program.
- To gain practical experience using EMU8086.

---

## ✨ Features

- 🧮 Decimal to Binary conversion
- 🔢 Decimal to Hexadecimal conversion
- 🔄 Binary to Decimal conversion
- 🔄 Hexadecimal to Decimal conversion
- 📋 Menu-driven interface
- 🔁 Loop-based processing
- 📚 Procedure-based program structure
- 📦 Stack-based digit reversal
- 🔤 ASCII character handling
- 🔷 Hexadecimal digit support
- 💻 8086 Assembly compatible
- 🖥️ Designed for EMU8086
